# 个人学术主页模板

单栏、简历式排版的学术主页模板，仅一个 `index.html` 文件，无需构建工具，可直接部署到 GitHub Pages。

## 修改内容

打开 `index.html`，替换以下示例信息为你本人的真实信息：

- 头部：姓名、英文名、职称、单位、邮箱与各类主页链接（GitHub / Google Scholar / ORCID）
- 简介段落
- 研究方向标签
- 教育背景、工作经历（时间 + 学校/单位）
- 代表性论文列表
- 项目与基金、荣誉奖励、教学工作、学术服务

页面顶部的绿色细线和各标题下方的短下划线是同一强调色 `--accent`，如需更换配色，只需修改 `<style>` 开头 `:root` 中的几个变量即可，无需改动其余代码。

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库：
   - 若想用作个人主站，仓库名设为 `你的用户名.github.io`；
   - 若只是某个项目的主页，仓库名任意即可。
2. 将本文件夹中的 `index.html` 放入仓库根目录并推送（commit + push）。
3. 打开仓库 **Settings → Pages**，在 "Build and deployment" 中将 Source 设为对应分支（通常是 `main`，目录选 `/ (root)`）。
4. 保存后等待一两分钟，即可通过以下地址访问：
   - 个人主站：`https://你的用户名.github.io/`
   - 项目页面：`https://你的用户名.github.io/仓库名/`

## 其他

- 页面右上角"导出 PDF"按钮会调用浏览器打印功能，方便快速生成一份纸质版简历。
- 页面已做移动端适配，窄屏下时间与内容会自动上下排列。
