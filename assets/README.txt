照片放这里
==========

把个人照片保存到本文件夹，然后在 content.md 的 frontmatter 里填写路径：

    photo: assets/photo.jpg

文件名随意（建议保持简短、用英文或拼音，避免空格），支持 jpg / png / webp / svg。
如果不想写相对路径，也可以直接填一张网上的图片地址。

形状由 content.md 的 photo_shape 决定，三选一：

    circle   圆形        174 x 174
    rounded  圆角矩形    174 x 218
    square   直角矩形    174 x 244   ← 5:7，与一寸/二寸证件照一致

原图不必裁成上述比例：页面会按比例铺满容器、多余的边缘自动裁掉，
并且优先保留画面顶部（人像构图时头部不会被切）。

建议尺寸 600 x 840 像素以上，文件控制在 500 KB 以内，页面加载更快。
